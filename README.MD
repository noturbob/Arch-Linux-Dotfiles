# 🏛️ agony's dotfiles

Welcome to my personal Arch Linux configuration repository, managed on a HP Victus. This setup is built around modern Wayland tools and a sleek, minimal aesthetic.

### 📦 What's Inside:
*   **Window Manager:** `niri` (Scrollable-tile window manager)
*   **Bar / Panels:** `waybar`
*   **Terminal:** `kitty`
*   **Application Launcher:** `fuzzel`
*   **Notifications:** `mako`
*   **System Info:** `fastfetch`
*   **Editor:** `vim`
*   **Theme & Extras:** `gtk-3.0` & curated `wallpapers`
